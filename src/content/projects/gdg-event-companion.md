## About GDG Event Companion

An installable organizer and attendee companion PWA with dashboard views for community events, speakers, session agendas, and venue navigation.

### Tech Stack
* **Framework:** Astro (Static Site Generation & Islands Architecture)
* **Styling:** Tailwind CSS 4
* **Language:** TypeScript
* **Offline & Capabilities:** Progressive Web App (PWA) with Service Workers (`sw.js`) and Web Manifest
* **Tooling:** ESLint, Prettier, and PDF parsing with `pdfjs-dist`

### What I Built
* Real-time session schedule browsing and personalized itinerary builder.
* Offline-first support via Service Workers for reliable access during high-density conferences.
* Clean, modular Astro architecture with high Lighthouse scores and zero bloat.
